# Карта интерфейса MVP

Это финальная граница UI. Если функции нет в этом файле и `TZ.md`, её не добавляем в MVP.

## Общий стиль

- Тёмный navy-фон, тонкие серо-синие границы, голубой акцент.
- Geist, скромные скругления, много воздуха.
- Только текстовые посты.

## Навигация авторизованного пользователя

`Сеть` | `Лента` | `Профиль` | меню пользователя: `Выйти`, `Активные сессии`

Никаких уведомлений, закладок, друзей, поиска, сообщений или общей страницы настроек.

## Экраны

| URL | Назначение | Главное содержимое |
| --- | --- | --- |
| `/` | Лента | поле нового текстового поста; карточки постов; лайк и комментарии |
| `/login` | Вход | email/username, пароль, кнопка «Войти», ссылка на регистрацию |
| `/register` | Регистрация | имя, username, email, пароль, подтверждение, кнопка регистрации |
| `/[username]` | Публичный профиль | аватар, имя, `@username`, посты пользователя |
| `/profile/edit` | Свой профиль | аватар, имя, username, сохранение изменений |
| `/sessions` | Активные сессии | устройство/браузер/IP/время, отзыв конкретной сессии |
| `/post/[id]` | Детали поста | пост, лайк, список комментариев, поле нового комментария |
